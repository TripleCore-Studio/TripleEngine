# TripleEngine
## 3D Game Engine
### Cloning
Clone:
```bash
git clone --recurse-submodules https://github.com/TripleCore-Studio/TripleEngine.git
```
Change dir:
```
cd Bebra-malware
```
### Build:
Create "build" and change dir:
```bash
mkdir build
cd build
```
Compile with CMake:
```bash
cmake ..
cmake --build .
```
