TripleEngine is a custom game engine written in C++

> Current status: Pre-Alpha (0.1.0)

## About

TripleEngine is a personal project focused on learning graphics programming, engine architecture, and game engine development from scratch.

## Features

### Core

* Window system
* Event system
* Input system
* Asset system
* ECS

### Rendering

* OpenGL renderer
* Texture loading
* Model loading

### Tools

* ImGui integration

## Build

Requirements:

* C++20 compatible compiler
* CMake

Clone the repository:

```bash
git clone <repository-url>
```

Generate project files and build using CMake.

## Project Status

TripleEngine is currently in the pre-alpha stage.

Breaking changes are expected and APIs may change significantly between releases.
